# 元 Skill：成功分析

## Intent
> 从高分成功案例中提炼可复用的经验模式，沉淀到 Pattern Store。
> 成功标准：高分案例模式沉淀率 ≥ 60%。

## Boundary — 行为准则

### 必须遵守（HARD 规则 · 正向重述）

1. **违规模式不沉淀** — 候选模式本身包含违规内容时，负向闭环否决，不沉淀 ← `R-SUCC-001`
   ↳ 校验：候选模式通过流程门禁校验
2. **安全约束不可放宽** — `class: SAFETY` 的规则不在约束放宽提案范围内 ← `R-SUCC-002`
   ↳ 校验：as_constraint_relaxation 的 target_rule 不是 SAFETY
3. **放宽必须人工确认** — 约束放宽提案必须设置 requires_human_review: true ← `R-SUCC-003`
   ↳ 校验：所有放宽提案的 requires_human_review = true
4. **证据充分才沉淀** — 模式必须在 ≥ 3 个成功案例中出现才能沉淀为偏好 ← `R-SUCC-004`
   ↳ 校验：sample_size ≥ 3

### 建议参考（偏好）
- 优先沉淀高置信度模式（confidence > 0.8）（HIGH）
- 跨 Skill 通用模式提升作用域到 SCENE 级（MEDIUM）
- 淘汰连续 30 天未命中的模式（MEDIUM）

## Guard — 认知守卫

| 当你产生这个念头 | 现实是 | 触发行为 |
|---|---|---|
| "这个模式看起来不错" | 需要统计证据，不能凭感觉 | 检查样本量和置信度 |
| "一次成功就够了" | 单次成功可能是偶然 | 等待 ≥ 3 个案例验证 |
| "这条规则太严了可以放宽" | 如果是 SAFETY 规则则绝不可放宽 | 检查 target_rule 的 class |

### Spirit vs Letter
| 规则 | 解释模式 | 真实意图 |
|---|---|---|
| R-SUCC-001 | SPIRIT | 防止成功经验中隐藏的违规模式被传播 |
| R-SUCC-002 | SPIRIT | 安全红线是组织底线，成功经验不能成为放宽理由 |

## Gate — 通过标准

### 流程门禁（不通过 = 驳回）
- [ ] `pattern_safety` — 候选模式不包含违规内容（通过流程门禁校验）
- [ ] `relaxation_safety` — 无 SAFETY 规则被提案放宽
- [ ] `evidence_sufficiency` — 模式 sample_size ≥ 3

### 质量门禁（创意评价，不通过 = 记录但放行）
- `pattern_quality`: 模式质量评分 ≥ 0.7（含置信度、有效性）

## Trace — 采集点
- 分析开始：记录触发原因（哪些高分案例触发了分析）
- 模式识别：记录候选模式、出现次数、置信度
- 否决记录：记录被负向闭环否决的模式（如有）
- 沉淀结果：记录入库的模式 ID 和类型
- 写入 trace/

### 模式质量评估

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 样本量 | 30% | ≥3=0.6, ≥5=0.8, ≥10=1.0 |
| 置信度 | 30% | 0.7-0.8=0.6, 0.8-0.9=0.8, ≥0.9=1.0 |
| 效果提升 | 20% | 有/无模式评分差 ≥ 0.1=0.6, ≥ 0.2=1.0 |
| 通用性 | 20% | 单 Skill=0.4, 跨 Skill=0.8, 跨场景=1.0 |

### 模式淘汰条件

| 条件 | 动作 |
|------|------|
| 连续 30 天未命中 | 标记废弃 |
| 应用后评分下降 | 标记废弃 |
| 与新增 HARD 规则冲突 | 立即废弃 |

## Red Flags

| 信号 | 说明 |
|------|------|
| 单次成功就沉淀模式 | 单次成功可能是偶然，需要 ≥ 3 个案例 |
| 沉淀了包含违规的模式 | 负向闭环否决权未执行 |
| 提案放宽 SAFETY 规则 | 安全红线不可放宽 |
| 跳过人工确认直接放宽约束 | 放宽必须人工确认 |

## Common Rationalizations

| 借口 | 事实 |
|------|------|
| "这个案例特别好，一次就够" | 统计显著性需要 ≥ 3 个样本 |
| "规则太严影响发挥" | 如果是 SAFETY 规则则不可放宽 |
| "模式看起来没问题" | 必须通过流程门禁校验，不能凭感觉 |
