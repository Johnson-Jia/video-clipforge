# 导演思维工具包 — 第 2 层：视觉词汇表

> 画家的颜料盘。不是"科技用蓝色"的查表，是理解每种视觉技术的情感效果后，根据内容自主组合。

### 色温叙事

色彩的情感效果不是固定的——同一个颜色在不同语境下传递不同情绪（案例见 cases.md）。但色温的**大方向**有规律可循：

**暖色（金/橙/琥珀）= 拉近**。让观众感觉亲切、紧迫、有价值。适合：数据增长、排名、星标、CTA、钩子中的数字。

**冷色（青/蓝/紫）= 推远**。让观众感觉理性、深邃、有距离感。适合：技术说明、功能描述、分析性内容。

**冷暖交替 = 叙事张力**。当一个场景从暖切到冷，观众能感受到情绪转换——即使他们没有意识到。

### 对比度控制

- **高对比**（纯白文字 + 纯黑背景 + 强 text-shadow）= 决定性瞬间。hook 场景、核心数据、高潮点。
- **中对比**（浅灰文字 + 深色背景）= 信息传递。正文、描述、功能说明。
- **低对比**（深灰文字 + 深色背景）= 氛围层。不该被第一眼注意到的装饰性信息。

### 光晕定位

大尺寸模糊光球（blur 140px）不是装饰——它是**氛围锚点**：
- **暖光在左上** + **冷光在右下** → 画面有纵深感和方向感
- **光晕位置跟随焦点** → 焦点在顶部时，光晕也偏上；焦点在底部时，光晕也偏下
- **双光晕一暖一冷** → 比单色光晕更有层次，避免画面"平"

### 留白密度

留白不是浪费空间，是**呼吸感**：
- **多留白（画面 40%+ 为空白）** = 高端、从容、呼吸感。适合：hook 场景（一句话冲击力）、climax（情感高点）
- **少留白（画面 20% 以下为空白）** = 紧迫、信息密集。适合：功能列表、数据展示、对比分析
- **同一视频内交替使用** → 用留白的多少制造节奏，不是所有场景都用同一个密度

### 动静节奏

- **快入快出（0.2-0.3s）** = 利落、专业、节奏紧凑。适合：列表项、标签、小元素入场
- **中速渐变（0.4-0.6s）** = 自然、舒适。适合：标题、主要文字
- **慢渐变（0.8-1.5s）** = 情绪化、沉浸。适合：phase 切换、氛围转变、climax 的视觉释放
- **静止** = 也是一种选择。不是每个元素都需要动画，静态本身是一种视觉力量

### 字号层级

字号不只是"大小"，是**视觉权重**的物理表现：

| 层级 | 字号范围 | 视觉角色 | 情感效果 |
|------|---------|---------|---------|
| 冲击层 | 100-140px | 钩子/核心数字/排名 | 震撼、不可忽视 |
| 标题层 | 50-70px | 场景标题/项目名 | 权威、聚焦 |
| 正文层 | 26-36px | 描述/说明/评语 | 阅读、理解 |
| 标签层 | 18-24px | 语言/类别/辅助信息 | 点缀、参考 |

**跨层级字号比 ≥ 2:1** 才能产生清晰的视觉层级。如果最大和最小的字号差距不到 2 倍，画面会"平"。
