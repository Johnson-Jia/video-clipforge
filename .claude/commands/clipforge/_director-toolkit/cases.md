# 导演思维工具包 — 第 3 层：导演笔记（爆款案例解码）

> 不是"这个视频用了什么"，而是"导演为什么在这里做这个选择"。通过案例理解决策逻辑，而非模仿表面。

### 案例 1：05-19 GitHub Trending（11 万播放）

**导演决策笔记：**

| 决策 | 导演为什么这样选择？ |
|------|-------------------|
| 金色 + 青色双色调 | 金色 = "增长/价值"的视觉隐喻；青色 = "技术/代码"的视觉隐喻。双色交替暗示"技术在涨值"——比单色更有叙事性 |
| 每个项目独占一屏 8 秒 | 观众一次只能消化一个概念。独占让注意力聚焦在单一故事上，不需要在信息间跳转 |
| 排名数字 120px + 金色 + text-shadow | "重要性排序"的视觉锚点。观众第一眼就知道"这是第几个"，建立心理预期。120px 确保即使快速划过也能捕捉 |
| 每场景一个暖光晕 + 一个冷光晕 | 比纯黑背景有温度，比单色光晕有层次。暖光偏左上、冷光偏右下，创造视觉纵深 |
| 40px 网格背景 opacity 0.04 | 几乎不可见但存在——给纯黑背景添加"数字纹理"，暗示科技感，而不分散注意力 |
| 描述用灰色而非白色 | 信息层级：排名/星标 > 项目名 > 描述。灰色让描述"可读但不抢"，保持焦点在上方 |

**关键教训：** 每个视觉选择背后都有一个"为什么"。如果你解释不出"为什么用这个颜色/字号/布局"，说明你在套公式而不是在做导演决策。

### 案例 2：色温叙事的经典案例

来自电影工业验证过的视觉叙事原理（[ECG Productions](https://www.ecgprod.com/video-color-grading-storytelling/)、[StudioBinder](https://www.studiobinder.com/blog/how-to-use-color-in-film-50-examples-of-movie-color-palettes/)）：

| 电影 | 色彩决策 | 导演为什么 | 短视频启示 |
|------|---------|-----------|-----------|
| 辛德勒名单 | 全黑白中唯一的红色外套 | 在死亡麻木中制造唯一的人性焦点，让观众无法移开目光 | hook 场景可以用"大面积冷色中一个暖色焦点"制造视觉锚点 |
| 黑客帝国 | Matrix 内所有场景带绿色调 | 暗示观众"你在虚拟世界里"——用色调编码现实层级 | 不同主题的场景可以用色调编码类别，让观众凭直觉区分 |
| 绝命毒师 | 黄色弥漫沙漠/制毒场景 | 黄色=化学腐蚀+道德堕落的双重隐喻 | 同一颜色可以承载多层含义——颜色不是装饰，是叙事工具 |
| 银翼杀手 2049 | 紫色光晕中的 AI 伴侣拥抱 | 紫色=人工亲密感，美丽但空洞。视觉本身在讲故事 | 光晕颜色可以暗示"这是什么性质的内容"——理性/感性/技术/人文 |

## 使用方式

| Stage | 使用第几层 | 怎么用 |
|-------|-----------|--------|
| **Stage 2** | 第 1 层 + 第 3 层 | 用 5 个必答题推导 design.md 的风格方向。参考第 3 层案例校准直觉 |
| **Stage 3** | 第 1 层 + 第 2 层 | 每个场景用 5 个必答题确定视觉描述。用第 2 层词汇表写出具体的视觉指令 |
| **Stage 6** | 第 2 层 + 第 3 层 | 读取 Stage 3 的视觉指令，用第 2 层词汇表选择具体的 CSS/GSAP 实现。参考第 3 层案例确认"为什么" |
