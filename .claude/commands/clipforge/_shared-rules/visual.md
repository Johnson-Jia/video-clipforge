# 共享规范 — 画面与视觉切换

> 适用于场景拆解（Stage 3）和 HTML 编写（Stage 6）。
> 规则 ID 与 `_rules-lib/global-rules.yaml` 对齐。

## 2. 画面文字语言规范

`R-GLOBAL-008` [HARD/EXPERIENTIAL]：**画面文字必须以中文为主**
- 正向：标题、副标题、标签、CTA 等画面可见文字全部用中文
- 仅以下情况用英文：项目名称（如 openhuman、scrcpy）、技术缩写（如 API、TTS、SDK）、编程语言名
- 校验：画面文字中英文占比 < 20%（项目名和技术缩写除外）
- 示例：
  - 正确："今天最热门"、"前三名"、"关注每天更新"
  - 禁止："TRENDING TODAY"、"TOP 3"、"FOLLOW FOR DAILY"
  - 例外：项目名（scrcpy、agentmemory）和技术缩写（API、Rust）保留英文

## 5. 黄金 3 秒法则（内容 + 画面）

> **用户划走一个视频只需 1-3 秒。** 前 3 秒决定生死，3-5 秒之后才能进入正文。

### 5.1 旁白文案

`R-GLOBAL-013` [HARD/EXPERIENTIAL]：**hook 场景旁白为纯钩子 ≤12 字**
- 正向：hook 旁白使用数据震撼/反问/强对比/悬念/情绪表达，≤12 字，不含信息性内容
- "正文"（项目介绍、功能说明等）从第 2 个场景开始，绝不提前
- 钩子句参考案例（不是模板，从内容中寻找最有力的一击）：
  - 数据震撼："今天涨星最猛的 N 个项目"、"N 个热门项目，AI 占了一半"
  - 反直觉描述："你见过用 WiFi 信号感知人体的吗"
  - 强对比："别人还在 XX，这个已经 YY"
  - 悬念留白："这个项目，三天涨了两万星"
  - 情绪表达："今天涨星直接炸了"

### 5.2 画面视觉

`R-GLOBAL-014` [HARD/EXPERIENTIAL]：**hook 场景为全片视觉最强画面**
- 正向：hook 画面极简——≤3 个元素，主标题 ≥100px，双色光晕（一暖一冷），留白 ≥30%
- 前 3 秒画面元素 ≤ 3 个（文字/数字/徽章），信息极简，视觉极强
- 主标题字号 ≥ 100px（竖屏基准），搭配光晕/发光效果
- 配色自由搭配：根据文案内容主题选择合适色系（科技用冷色、生活用暖色等），主色 + 强调色双色体系，禁止超过 3 种颜色，禁止荧光色堆砌
- 必须包含双色光晕：一暖一冷两个大尺寸模糊光球，颜色随主题变化
- 布局固定模板：元素间距均匀、对齐严整、留白充裕（画面 30% 以上为留白）
- 入场动画 0.3-0.5 秒内完成，干脆利落不拖泥带水

### 5.3 音频开场（禁止淡入）

`R-GLOBAL-015` [HARD/EXPERIENTIAL]：**视频开头旁白和 BGM 第一帧立即全音量**
- 正向：旁白 TTS 第一段保持原始开头，BGM `data-start="0"` + `data-volume` 直接生效
- 禁止任何形式的音频淡入（`afade=t=in`）
- **原因：** 前 3 秒是钩子生死线，淡入会让观众在最重要的时刻听到渐强的声音而非冲击性的信息
- 尾巴可以淡出：视频最后 1 秒 BGM 淡出是允许的

## 6. 视觉切换频率（跨阶段引用）

> **适用于所有视频模式。** Stage 3 场景拆解和 Stage 6 HTML 编写时必须遵守。

**核心原则：人眼在静态画面上的注意力极限约 8-12 秒。超过此阈值不切换视觉内容，观众注意力开始游离。**

`R-GLOBAL-016` [HARD/EXPERIENTIAL]：**遵守视觉切换频率表**

| 场景时长 | 视觉切换要求 | 说明 |
|---------|------------|------|
| ≤ 10 秒 | 1 个 phase，入场动画 + 静态展示 | 短视频标准场景，一个画面足够 |
| 10-20 秒 | ≥ 2 个 phase | 必须拆分，每 phase ≤ 12 秒 |
| 20-40 秒 | ≥ 3 个 phase | 每 phase ≤ 14 秒 |
| > 40 秒 | ⌈duration / 14⌉ 个 phase | 按此公式计算最少 phase 数 |

- **Phase** = clip 内的一次视觉内容切换（不是新 clip，不拆分音频）
- Phase 间切换由 GSAP timeline 驱动（详见 `_render-safety.md` §1.1a 和 `stage6-production.md` §6.4a）
- Phase 切换 ≠ 硬切：使用 opacity 渐变过渡（0.3-0.4s），上一个 phase 淡化到 0（完全消失，避免重叠重影），新 phase 从 0 渐显到 1
- **相邻 phase 的 visual_type 不应重复**（视觉多样性）

`R-GLOBAL-017` [HARD/EXPERIENTIAL]：**Phase 断点与旁白话题转换对齐**
- 正向：逐场景分析旁白文本，找到与 visual_phases focus 匹配的话题边界，按字数比例换算时间戳
- 禁止时间均分——详见 `stage6-production.md` §6.4b
