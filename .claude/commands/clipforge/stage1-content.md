# Stage 1: 内容获取

## Intent
> 获取并验证内容源，确保信息密度足以支撑视频制作。
> 成功标准：内容源已获取并整理为可分析格式，信息密度满足视频场景需求，分类数据验证通过。

## Boundary — 行为准则

### 必须遵守（HARD 规则 · 正向重述）

1. **禁用缓存获取最新数据** — 调用 web-reader 时设置 `no_cache: true` ← `R-STAGE1-001`
   ↳ 校验：web-reader 调用参数中 `no_cache: true`
2. **内容密度不足时停止** — 信息点不足以支撑视频时，要求用户补充内容 ← `R-STAGE1-002`
   ↳ 校验：评估可提取核心信息点数量 vs 目标场景数
3. **遵守分类配置验证规则** — 读取分类配置的 `content` 段，执行其中定义的数据验证步骤 ← `R-STAGE1-003`
   ↳ 校验：分类配置要求的验证步骤（如双源交叉验证）是否已全部执行

### 建议参考（偏好）
- 优先使用用户直接提供的内容，减少额外获取步骤（HIGH）

## Guard — 认知守卫

| 当你产生这个念头 | 现实是 | 触发行为 |
|---|---|---|
| "这些数据看起来合理" | 看起来合理 ≠ 数据准确 | 执行分类配置的验证规则 |
| "跳过数据验证，直接开始" | 错误数据进入视频→观众纠正→伤害可信度 | 执行完整验证流程 |
| "内容不够但先做着" | 内容不足导致视频空洞、节奏拖沓 | 停止并要求补充内容 |

### Spirit vs Letter

| 规则 | 模式 | 真实意图 |
|---|---|---|
| R-STAGE1-003 | SPIRIT | 确保视频内容的数据准确性，维护频道可信度 |

## Gate — 通过标准

### 流程门禁（自动化检查，不通过 = 驳回，max_retries: 1）
- [ ] `data_validation` — 分类配置要求的数据验证步骤已全部通过

### 质量门禁（创意评价，不通过 = 记录但放行，evaluator: HUMAN）
- `content_sufficiency`: 内容核心信息点足以支撑目标视频时长的场景（人类评价）

## Trace — 采集点
- **执行开始**：记录内容来源类型（对话/文件/URL/分类配置）
- **获取完成**：记录获取的数据量、来源 URL/路径
- **验证完成**：记录验证步骤执行结果（通过/失败）
- **执行结束**：记录 gate_report + 产出内容摘要
- **写入**：`{project_dir}/trace/stage1-{timestamp}.yaml`

## 操作指令

### 内容来源

来源可能是：
- 对话中直接描述
- 指定目录下的文件（md/txt/html/json）
- 用户粘贴的文字或 HTML
- 网页 URL
- PDF / Word / Excel / PPT 文件
- 以上组合

### 决策树

1. 用户已给出 → 直接用
2. 指定目录 → 扫描内容文件（跳过 CLAUDE.md / AGENTS.md / README.md）
3. HTML 文件 → 提取 `<body>` 纯文本，忽略标签和样式
4. 不明确 → 询问：「请提供视频内容来源——文字、文件、还是目录？」

**获取后：** 提炼核心信息点，准备进入 Stage 2 风格推导。

### 分类数据获取（当有分类配置时）

当用户指定了内容分类（如 GitHub、漫画、小说等），读取对应的分类配置文件获取数据获取策略：

```
clipforge/categories/{category}.md
```

分类配置中的 `content` 段定义了该分类特有的数据获取方式、选取策略和兜底方案。通用部分（文件提取、URL 读取等）在本文件前面已覆盖。

**如果没有分类配置**（用户直接提供文字/文件/URL），则只使用本文件前面的通用内容获取流程。

## Red Flags

| 信号 | 说明 |
|------|------|
| 分类数据未按配置验证 | 分类配置中的数据验证规则（如双源交叉验证）必须遵守 |
| 内容量不足以支撑视频 | 信息密度不够时停止，要求用户提供更多内容 |
| web-reader 未禁缓存 | 必须设置 `no_cache: true`，否则可能获取过期数据 |

## Common Rationalizations

| 借口 | 事实 |
|------|------|
| "这些数据看起来合理" | 看起来合理 ≠ 数据准确。分类配置中的验证规则必须遵守 |
| "跳过数据验证，直接开始" | 错误数据进入视频 → 观众纠正 → 伤害频道可信度 |
| "内容不够但先做着" | 内容不足会导致视频空洞、节奏拖沓，必须补充后再继续 |
