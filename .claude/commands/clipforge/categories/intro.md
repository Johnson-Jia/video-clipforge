# 频道介绍分类配置

## content

### data_source

无外部数据源。内容完全由以下维度自生成：

| 维度 | 来源 | 说明 |
|------|------|------|
| 频道名称 | 用户指定或 CLAUDE.md | 如 "GitHub星探" |
| 频道定位 | 用户指定 | 如 "讲开源项目的频道" |
| 核心理念 | 用户指定或从频道名推导 | 如 "开源精神"、"分享精神" |
| 视觉主题 | 从核心理念推导 | 如 "星火"→ 火焰/光芒/燎原 |
| 情感目标 | 通用：建立信任和归属感 | 所有 intro 视频共通 |

### content_framework — 八段叙事弧

intro 视频采用固定的八段弧线结构，每段有明确的叙事功能和情感定位：

```
hook → proof → faith → whatif → multiply → climax → you → cta
 好奇    敬佩     肃穆     憧憬      激昂      史诗     温暖    行动
```

| # | 场景 | 叙事功能 | 情感 | 时长参考 | 视觉关键词 |
|---|------|---------|------|---------|-----------|
| 1 | **hook** | 感恩 + 提问，建立亲密感 | 好奇/温暖 | 10-13s | 星空/暖光 + 钩子文字 |
| 2 | **proof** | 具体例子证明核心理念真实存在 | 敬佩 | 8-11s | 案例 + 数据/人名 |
| 3 | **faith** | 揭示精神内核，全片最肃穆处 | 肃穆/庄严 | 6-8s | 暖光晕 + 大字居中 |
| 4 | **whatif** | 从具体延展到抽象，打开想象 | 憧憬 | 6-9s | 扩展光效 + 问句 |
| 5 | **multiply** | 数字递进加速，制造紧迫感 | 激昂 | 7-9s | 数字叠加 + 动态粒子 |
| 6 | **climax** | 核心隐喻全释放，全片最高潮 | 史诗/燃烧 | 18-22s | 火焰/星火 + 密集特效 |
| 7 | **you** | 从宏大落回个人，温暖收束 | 温暖/归属 | 5-7s | 柔光 + 你 = 隐喻 |
| 8 | **cta** | 行动号召 + 长期承诺 | 行动/期待 | 7-10s | 光芒 + CTA文案 |

**场景数**：固定 8 个。intro 视频的信息密度低于内容视频，需要更多呼吸空间。

**总时长**：70-90 秒（比标准模式长，因为需要完整的情感弧线）。

### narrative_arc — 情感弧线设计

```
情感强度
    │          ★ climax
    │        ╱   ╲
    │      ╱      you
    │    ╱          ╲  cta
    │  multiply       ╲╱
    │ ╱
    │╱ whatif
    │  faith
    │proof
    │hook
    └──────────────────────→ 时间
```

**弧线规则**：
- 情感从 hook（温和好奇）持续上升到 climax（史诗高潮）
- climax 后必须在 you 处急转下行（从宏大→个人），形成情感落差
- cta 在低位稳定收尾，不回到高潮，留下"继续走"的期待
- proof 和 faith 是两个"扎根点"——用具体事实和精神内核锚住情感，防止空泛

### visual_theme — 视觉主题推导

从核心理念推导视觉主题词和对应的视觉元素：

| 核心理念 | 视觉主题 | 主色 | FX 元素 | 渐变强调色 |
|---------|---------|------|---------|-----------|
| 开源/分享 | 星火燎原 | 琥珀 #FFB800 | 火星 + 光晕 + 环形波 | 金→青 #FFD700→#64FFDA |
| 知识/学习 | 星辰大海 | 靛蓝 #4169E1 | 星点 + 轨迹 + 脉冲 | 银→蓝 #C0C0C0→#00BFFF |
| 创造/构建 | 聚沙成塔 | 翠绿 #2E8B57 | 粒子聚合 + 生长 + 层叠 | 绿→金 #32CD32→#FFD700 |
| 连接/社区 | 百川归海 | 珊瑚 #FF6347 | 流动 + 汇聚 + 波纹 | 橙→紫 #FF8C00→#9370DB |
| 探索/发现 | 破晓之光 | 金色 #FFD700 | 光线 + 展开 + 晨曦 | 金→白 #FFD700→#FFFACD |

**推导规则**：
1. 从用户给出的核心理念匹配上表
2. 无匹配时，选择"积极向上"方向的隐喻
3. 避免消极/压迫性主题
4. 渐变强调色必须与主色形成冷暖对比

### metaphor_design — 核心隐喻设计

intro 视频需要一个贯穿全片的核心隐喻。设计方法：

1. **从理念提炼隐喻词**：开源 → 星火，知识 → 星辰，创造 → 积木
2. **隐喻三段式**：
   - 第一段（proof/faith）：隐喻引入 — "每一行开源代码是一颗星火"
   - 第二段（multiply/climax）：隐喻展开 — 排比 + 递进
   - 第三段（you/cta）：隐喻回归个人 — "你已经是其中一簇星火了"
3. **隐喻与视觉同步**：climax 场景的 FX 必须是隐喻的可视化（星火→火焰，星辰→星空）

### fallback

intro 视频不依赖外部数据，无数据获取失败场景。如果用户未提供频道信息：
- 从 CLAUDE.md 或项目路径推断频道名
- 从最近的视频内容推断频道定位
- 使用通用框架，用占位符标记需要用户确认的部分

## design

### default_style

暖色星空风。背景以深空黑（#040810）为基底，暖琥珀光晕（#FFB800）营造氛围，金青渐变（#FFD700→#64FFDA）用于强调文字。整体感觉：深夜对谈、星空下的真诚分享。

### color_bias

暖色为主（琥珀/金色），搭配冷色强调（青色/薄荷绿）形成冷暖对比。禁止纯冷色方案——intro 视频需要温暖感建立信任。

### design_system — 视觉设计体系

#### 配色规范

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 | `#040810` ~ `#0c0c14` | 背景基底，深空黑 |
| 主色 | `#FFB800` (amber) | 光晕、分隔线、标签 |
| 火色 | `#FF6B00` (fire) | 渐变终点、climax 强调 |
| 奶油色 | `#F0E8DA` (cream) | 正文文字 |
| 弱化色 | `rgba(240,232,218,0.6)` | 次要文字 |
| 金色 | `#FFF5E6` (gold) | 标题、高亮 |
| 渐变强调 | `#FFD700→#64FFDA` | 关键短语的金青渐变 |
| 主渐变 | `amber→fire` | `.g` class 专用渐变 |

#### 手机可读性标准

intro 视频通常在信息流中被推荐给新观众，手机可读性是第一优先级：

| 规则 | 标准 | 原因 |
|------|------|------|
| 暖光晕 opacity | ≥ 0.25 | < 0.15 在手机上等同黑屏 |
| 正文字号 | ≥ 36px | 手机屏幕有效分辨率低 |
| 标题字号 | ≥ 46px | 钩子文字必须远距离可读 |
| 渐变文字 | 必须用 `background-image`，禁止 `background` 简写 | 简写导致渲染失败 |
| 渐变 + 阴影 | 渐变文字不加 `text-shadow` | HyperFrames 渲染异常 |

#### 三层架构

| 层 | z-index | 内容 |
|----|---------|------|
| bg | 1 | 基底渐变 + 暖光晕（≥ 0.25）+ 微妙纹理 |
| fx | 2 | 星点 + 光圈 + 火星/粒子（climax 场景 ≥ 2 种特效） |
| content | 3 | 文字内容，phase 用 `position:absolute;inset:0` 叠加 |

#### Phase 叠加规则

多个 phase（如 phase-1/phase-2）必须脱离文档流互相叠加：

```html
<div class="phase phase-1" style="position:absolute;inset:0;opacity:0;padding-top:600px;height:auto">
<div class="phase phase-2" style="position:absolute;inset:0;opacity:0;padding:100px 80px;height:auto">
```

**禁止**用 `margin-top`/`margin-bottom` 控制 phase 位置——`.phase` class 的 `height:100%;justify-content:center` 会覆盖 margin 效果。

## narration

### scene_templates — 场景文案模板

每个场景提供通用模板，从核心理念和隐喻填充：

**1. hook（感恩+提问）**
```
感谢你点亮了{频道名}！{一个引人思考的问题}？
{回答方向暗示}——{频道定位的核心人群}。
```

**2. proof（具体证据）**
```
{具体人物/事件}，{做了什么}，{结果如何}；
{另一个案例}，{原因}，"({一句话金句})"。
```

**3. faith（精神内核）**
```
这就是{核心理念}——它本质上是一种{升华词}：
{行为}，不是因为{功利原因}，而是因为{精神原因}。
```

**4. whatif（延展想象）**
```
如果这种{精神}不只是存在于{当前领域}呢？
如果每个人都愿意{具体行为}呢？
```

**5. multiply（数字递进）**
```
{1个人}{行为}，{帮助N个人}；
{N个人}{行为}，{帮助N²个人}；
当{行为}成为潮流，{进步}就不是{加法}，而是{乘法}。
```

**6. climax（核心隐喻全释放）**
```
{隐喻引用/名句}。
{隐喻三排比}——{对象A}是{隐喻}，{对象B}是{隐喻}，{对象C}也是{隐喻}。
当{隐喻}汇聚，就能{高潮动作}——{愿景描述}——
{三个排比短句}——{收束金句}。
```

**7. you（回归个人）**
```
而你{与观众相关的行为}，就已经是{隐喻延伸}了。
让我们一起，{隐喻主题}。
```

**8. cta（行动号召）**
```
感谢你的{关注行为}！
{观众行为}，都是对{核心理念}的一次{正面评价}。
{隐喻延伸 Slogan}。
接下来的{时间框架}，咱们一起走。
```

### hook_templates

intro 视频的 hook 不依赖数据，而是情感驱动：

| 优先级 | 模式 | 模板 |
|--------|------|------|
| 1 | 感恩+提问 | "感谢你点亮了{频道名}！{思考性问题}？" |
| 2 | 反问共鸣 | "什么样的人会{行为}？答案大概是——{人群画像}。" |
| 3 | 直接宣言 | "这个频道只做一件事：{核心使命}。" |

### special_rules

- **禁止真实人名**：平台合规，不出现任何政治/历史人物名称，即使是引用名句
- **禁止搜索引导**：不说"搜XX"、"去XX平台找"
- **排比用三次**：proof 和 climax 场景各一个三排比，制造节奏感
- **金句收尾**：每个长场景最后一句必须是可独立的金句
- **情感递进不回退**：一旦进入更高情感层级，不再降回（climax→you 除外）

### word_count_range

350-500 字。intro 视频字数多于内容视频，因为需要铺满情感弧线。

### pacing_rules — 节奏控制

| 场景 | 语速 | 停顿 | 说明 |
|------|------|------|------|
| hook | 正常 | 句间 0.5s | 像对朋友说话 |
| proof | 正常偏快 | 无额外停顿 | 用节奏感制造敬佩 |
| faith | 放慢 10% | 金句前 0.8s | 全片最肃穆，给金句留白 |
| whatif | 正常 | 两个问句间 0.5s | 问句制造悬念 |
| multiply | 加速 | "乘法"前 0.3s | 递进加速，"乘法"做释放 |
| climax | 正常偏快 | 排比间 0.3s | 节奏紧凑，三排比一气呵成 |
| you | 放慢 10% | "让我们一起"前 0.5s | 温暖收束，让情感着陆 |
| cta | 正常 | slogan 后 0.5s | 稳定收尾 |

## narrative

### default_template

`emotional-arc` — 固定使用八段情感弧线模板，不使用标准模式的 `contrast-arc`。

### humor_rules

intro 视频幽默权重低于内容视频：
- 轻微自嘲可用（"答案大概是——像我这样的理想主义者"）
- 避免吐槽型幽默——intro 视频需要真诚感
- humor 密度 ≤ 20%（内容视频是 30%）

### character_presence

false — intro 视频不启用虚拟主持人角色，以第一人称"我"和第二人称"你"直接对话。

### immersion_mapping

intro 视频使用统一的 `warm-starlight` 沉浸模式，不按内容标签切换：

| 元素 | 规范 |
|------|------|
| bg 暖光晕 | opacity ≥ 0.25，手机可读 |
| fx 星点 | 星星缓慢漂移（duration = 场景时长） |
| fx 光圈 | 每场景 1 个 ring 缓慢扩张 |
| content 淡入 | `opacity:0` → `opacity:1`，duration 0.6-0.8s |
| climax 特效 | 至少 2 种不同类型特效元素（火星 + 光晕等） |

## shared-rules

### content_safety

intro 视频是频道门面，内容安全标准高于常规视频：

| 规则 | 说明 |
|------|------|
| 禁止政治人物名称 | 即使引用名句也不标注出处（"星星之火，可以燎原"不说谁说的） |
| 禁止搜索引导 | 不说"搜项目名"、"去XX平台" |
| 禁止绝对化用语 | 不说"最好的"、"唯一的" |
| 禁止竞品拉踩 | 不提其他频道/平台 |
| 禁止真实人名 | proof 场景的案例用"某开发者"代替真名（"Linus"等知名开源人物除外） |

### Red Flags（intro 特定）

| 信号 | 说明 |
|------|------|
| 场景数 ≠ 8 | intro 视频固定 8 个场景，不能删减 |
| hook 无提问 | hook 必须包含一个引人思考的问题 |
| climax 无排比 | climax 必须有 ≥ 3 的排比结构 |
| you 不提及观众 | you 场景必须用"你"直接称呼观众 |
| 总时长 < 60s | intro 需要完整情感弧线，60s 以下弧线不完整 |
| 出现政治人物名称 | 平台合规红线，必须移除 |

### Common Rationalizations（intro 特定）

| 借口 | 事实 |
|------|------|
| "intro 不需要这么长" | 情感弧线需要空间展开。太短的 intro 无法建立信任 |
| "删掉 faith/whatif 场景节省时间" | 每个场景有不可替代的情感功能。删减 = 弧线断裂 |
| "climax 不需要排比" | 排比是 climax 的核心节奏装置，没有排比就没有高潮感 |
| "出处标注让引用更有说服力" | 说服力来自内容本身，不是出处。标注政治人物名 = 平台风险 |
| "BGM 随便选一首就行" | intro 的 BGM 承载情感弧线，选错 = 情感断裂 |
