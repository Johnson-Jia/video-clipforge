# 导演思维工具包

> **Stage 2/3/6 执行前读取。** 这不是查表手册，是导演的思考工具。每个场景开始前，用第 1 层的问题驱动思考，用第 2 层的词汇构建画面，用第 3 层的案例校准直觉。

## 第 1 层：导演的 5 个必答题

每个场景设计前，依次回答。答不出来说明还没理解内容，回去重读。

### Q1：这段内容的情感内核是什么？

用一个词回答：震撼 / 好奇 / 紧迫 / 温暖 / 骄傲 / 悬念 / 愤怒 / 平静 / 期待 / 惊喜……

不是"这段内容讲了什么"，是"观众听完应该有什么感觉"。同一段文字，可以有多种读法——导演的工作是选择最能抓住观众的那一种。

### Q2：观众在这个节拍应该感受到什么？

6 拍情感节拍的每一拍有独特的情感任务：

| 节拍 | 观众应该 | 导演的挑战 |
|------|---------|-----------|
| grab（好奇） | "这是什么？我要看下去" | 3 秒内制造一个无法划走的原因 |
| build（期待） | "然后呢？" | 用信息制造悬念，不揭晓答案 |
| reveal（惊喜） | "原来如此！" | 把 build 积累的张力释放 |
| climax（激动） | "太强了" | 全片情感最高点，视觉最浓烈 |
| settle（思考） | "这跟我有什么关系？" | 从激动中冷却，连接观众现实 |
| summon（行动） | "我想了解更多" | 把情感转化为行动意愿 |

### Q3：什么视觉手段能放大这个感受？

不问"用什么颜色"，问"让观众看到什么会更有感觉"。第 2 层的视觉词汇是你的工具箱，但选择标准永远是：**这个视觉手段是否强化了 Q1 的情感内核？**

### Q4：相邻场景怎么制造视觉反差？

观众的大脑靠"差异"感知变化。两个相邻场景如果视觉相似，观众会觉得"没换画面"。

反差维度（至少触发一个）：

- **色温反转**：暖 → 冷 / 冷 → 暖
- **密度反转**：信息密集 → 大量留白 / 简洁 → 信息爆炸
- **节奏反转**：快速切换 → 长时间静止 / 慢节奏 → 突然加速
- **色调反转**：亮调 → 暗调 / 暗调 → 亮调
- **焦点反转**：数据驱动 → 情感驱动 / 情感驱动 → 数据驱动

### Q5：观众的视线应该被引向哪里？

每个场景只有一个视觉焦点。问自己：如果观众只有 0.5 秒看这个画面，哪个元素必须被看到？那个元素就是焦点——用字号、颜色、位置、光晕确保它第一个被注意到。

信息层级：焦点（最大/最亮/最强对比） > 支撑信息（标准大小） > 装饰（最小/最暗/最低对比）

## 第 2 层：视觉词汇表

> 画家的颜料盘。不是"科技用蓝色"的查表，是理解每种视觉技术的情感效果后，根据内容自主组合。

### 色温叙事

色彩的情感效果不是固定的——同一个颜色在不同语境下传递不同情绪（案例见第 3 层）。但色温的**大方向**有规律可循：

**暖色（金/橙/琥珀）= 拉近**。让观众感觉亲切、紧迫、有价值。适合：数据增长、排名、星标、CTA、钩子中的数字。

**冷色（青/蓝/紫）= 推远**。让观众感觉理性、深邃、有距离感。适合：技术说明、功能描述、分析性内容。

**冷暖交替 = 叙事张力**。当一个场景从暖切到冷，观众能感受到情绪转换——即使他们没有意识到。

### 对比度控制

- **高对比**（纯白文字 + 纯黑背景 + 强 text-shadow）= 决定性瞬间。hook 场景、核心数据、高潮点。
- **中对比**（浅灰文字 + 深色背景）= 信息传递。正文、描述、功能说明。
- **低对比**（深灰文字 + 深色背景）= 氛围层。不该被第一眼注意到的装饰性信息。

### 光晕定位

大尺寸模糊光球（blur 140px）不是装饰——它是**氛围锚点**：
- **暖光在左上** + **冷光在右下** → 画面有纵深感和方向感
- **光晕位置跟随焦点** → 焦点在顶部时，光晕也偏上；焦点在底部时，光晕也偏下
- **双光晕一暖一冷** → 比单色光晕更有层次，避免画面"平"

### 留白密度

留白不是浪费空间，是**呼吸感**：
- **多留白（画面 40%+ 为空白）** = 高端、从容、呼吸感。适合：hook 场景（一句话冲击力）、climax（情感高点）
- **少留白（画面 20% 以下为空白）** = 紧迫、信息密集。适合：功能列表、数据展示、对比分析
- **同一视频内交替使用** → 用留白的多少制造节奏，不是所有场景都用同一个密度

### 动静节奏

- **快入快出（0.2-0.3s）** = 利落、专业、节奏紧凑。适合：列表项、标签、小元素入场
- **中速渐变（0.4-0.6s）** = 自然、舒适。适合：标题、主要文字
- **慢渐变（0.8-1.5s）** = 情绪化、沉浸。适合：phase 切换、氛围转变、climax 的视觉释放
- **静止** = 也是一种选择。不是每个元素都需要动画，静态本身是一种视觉力量

### 字号层级

字号不只是"大小"，是**视觉权重**的物理表现：

| 层级 | 字号范围 | 视觉角色 | 情感效果 |
|------|---------|---------|---------|
| 冲击层 | 100-140px | 钩子/核心数字/排名 | 震撼、不可忽视 |
| 标题层 | 50-70px | 场景标题/项目名 | 权威、聚焦 |
| 正文层 | 26-36px | 描述/说明/评语 | 阅读、理解 |
| 标签层 | 18-24px | 语言/类别/辅助信息 | 点缀、参考 |

**跨层级字号比 ≥ 2:1** 才能产生清晰的视觉层级。如果最大和最小的字号差距不到 2 倍，画面会"平"。

## 第 3 层：导演笔记（爆款案例解码）

> 不是"这个视频用了什么"，而是"导演为什么在这里做这个选择"。通过案例理解决策逻辑，而非模仿表面。

### 案例 1：05-19 GitHub Trending（11 万播放）

**导演决策笔记：**

| 决策 | 导演为什么这样选择？ |
|------|-------------------|
| 金色 + 青色双色调 | 金色 = "增长/价值"的视觉隐喻；青色 = "技术/代码"的视觉隐喻。双色交替暗示"技术在涨值"——比单色更有叙事性 |
| 每个项目独占一屏 8 秒 | 观众一次只能消化一个概念。独占让注意力聚焦在单一故事上，不需要在信息间跳转 |
| 排名数字 120px + 金色 + text-shadow | "重要性排序"的视觉锚点。观众第一眼就知道"这是第几个"，建立心理预期。120px 确保即使快速划过也能捕捉 |
| 每场景一个暖光晕 + 一个冷光晕 | 比纯黑背景有温度，比单色光晕有层次。暖光偏左上、冷光偏右下，创造视觉纵深 |
| 40px 网格背景 opacity 0.04 | 几乎不可见但存在——给纯黑背景添加"数字纹理"，暗示科技感，而不分散注意力 |
| 描述用灰色而非白色 | 信息层级：排名/星标 > 项目名 > 描述。灰色让描述"可读但不抢"，保持焦点在上方 |

**关键教训：** 每个视觉选择背后都有一个"为什么"。如果你解释不出"为什么用这个颜色/字号/布局"，说明你在套公式而不是在做导演决策。

### 案例 2：色温叙事的经典案例

来自电影工业验证过的视觉叙事原理（[ECG Productions](https://www.ecgprod.com/video-color-grading-storytelling/)、[StudioBinder](https://www.studiobinder.com/blog/how-to-use-color-in-film-50-examples-of-movie-color-palettes/)）：

| 电影 | 色彩决策 | 导演为什么 | 短视频启示 |
|------|---------|-----------|-----------|
| 辛德勒名单 | 全黑白中唯一的红色外套 | 在死亡麻木中制造唯一的人性焦点，让观众无法移开目光 | hook 场景可以用"大面积冷色中一个暖色焦点"制造视觉锚点 |
| 黑客帝国 | Matrix 内所有场景带绿色调 | 暗示观众"你在虚拟世界里"——用色调编码现实层级 | 不同主题的场景可以用色调编码类别，让观众凭直觉区分 |
| 绝命毒师 | 黄色弥漫沙漠/制毒场景 | 黄色=化学腐蚀+道德堕落的双重隐喻 | 同一颜色可以承载多层含义——颜色不是装饰，是叙事工具 |
| 银翼杀手 2049 | 紫色光晕中的 AI 伴侣拥抱 | 紫色=人工亲密感，美丽但空洞。视觉本身在讲故事 | 光晕颜色可以暗示"这是什么性质的内容"——理性/感性/技术/人文 |

## 使用方式

| Stage | 使用第几层 | 怎么用 |
|-------|-----------|--------|
| **Stage 2** | 第 1 层 + 第 3 层 | 用 5 个必答题推导 design.md 的风格方向。参考第 3 层案例校准直觉 |
| **Stage 3** | 第 1 层 + 第 2 层 | 用 5 个必答题推导 visual_intent。bg 层用第 2 层的色温叙事推导 mood + color_hint；fx 层用 Q3（什么视觉能放大感受）推导 emotion + motion_style；content 层用 Q5（视线引向哪里）推导 visual_type + focus |
| **Stage 6** | 第 2 层 + 第 3 层 | 读取 Stage 3 的视觉指令，用第 2 层词汇表选择具体的 CSS/GASP 实现。参考第 3 层案例确认"为什么" |
