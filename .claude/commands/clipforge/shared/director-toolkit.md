# 导演思维工具包

> **Stage 2/3/6 执行前读取。** 第 1 层驱动思考，第 2 层构建画面，第 3 层校准直觉。

## 第 1 层：导演的 5 个必答题

每个场景设计前，依次回答。答不出来说明还没理解内容，回去重读。

### Q1：这段内容的情感内核是什么？

用一个词回答：震撼 / 好奇 / 紧迫 / 温暖 / 骄傲 / 悬念 / 愤怒 / 平静 / 期待 / 惊喜……

不是"这段内容讲了什么"，是"观众听完应该有什么感觉"。同一段文字，可以有多种读法——导演的工作是选择最能抓住观众的那一种。

### Q2：观众在这个节拍应该感受到什么？

6 拍情感节拍的每一拍有独特的情感任务：

| 节拍 | 观众应该 | 导演的挑战 |
|------|---------|-----------|
| grab（好奇） | "这是什么？我要看下去" | 3 秒内制造一个无法划走的原因 |
| build（期待） | "然后呢？" | 用信息制造悬念，不揭晓答案 |
| reveal（惊喜） | "原来如此！" | 把 build 积累的张力释放 |
| climax（激动） | "太强了" | 全片情感最高点，视觉最浓烈 |
| settle（思考） | "这跟我有什么关系？" | 从激动中冷却，连接观众现实 |
| summon（行动） | "我想了解更多" | 把情感转化为行动意愿 |

### Q3：什么视觉手段能放大这个感受？

不问"用什么颜色"，问"让观众看到什么会更有感觉"。第 2 层的视觉词汇是你的工具箱，但选择标准永远是：**这个视觉手段是否强化了 Q1 的情感内核？**

### Q4：相邻场景怎么制造视觉反差？

观众的大脑靠"差异"感知变化。两个相邻场景如果视觉相似，观众会觉得"没换画面"。

反差维度（至少触发一个）：

- **色温反转**：暖 → 冷 / 冷 → 暖
- **密度反转**：信息密集 → 大量留白 / 简洁 → 信息爆炸
- **节奏反转**：快速切换 → 长时间静止 / 慢节奏 → 突然加速
- **色调反转**：亮调 → 暗调 / 暗调 → 亮调
- **焦点反转**：数据驱动 → 情感驱动 / 情感驱动 → 数据驱动

### Q5：观众的视线应该被引向哪里？

每个场景只有一个视觉焦点。问自己：如果观众只有 0.5 秒看这个画面，哪个元素必须被看到？那个元素就是焦点——用字号、颜色、位置、光晕确保它第一个被注意到。

信息层级：焦点（最大/最亮/最强对比） > 支撑信息（标准大小） > 装饰（最小/最暗/最低对比）

**画布方向决定构图逻辑：**

- **竖屏（1080×1920）**：垂直纵深是最大资产。焦点通常在中上部（黄金分割点 ~38%），利用纵向空间做信息层叠。标题在上、正文在中、装饰在下。一行放不下就换行，不要压缩字号
- **横屏（1920×1080）**：水平空间充裕。视觉重心分布在画布中段（不偏向一侧），利用水平空间做并排对比和信息密度。单栏内容容器居中（max-width+margin:0 auto），文字可左对齐；双栏/多栏利用全宽但保持左右平衡

## 第 2 层：视觉词汇表

> 画家的颜料盘。不是"科技用蓝色"的查表，是理解每种视觉技术的情感效果后，根据内容自主组合。

### 色温叙事

色彩的情感效果不是固定的——同一个颜色在不同语境下传递不同情绪（案例见第 3 层）。但色温的**大方向**有规律可循：

**暖色（金/橙/琥珀）= 拉近**。让观众感觉亲切、紧迫、有价值。适合：数据增长、排名、星标、CTA、钩子中的数字。

**冷色（青/蓝/紫）= 推远**。让观众感觉理性、深邃、有距离感。适合：技术说明、功能描述、分析性内容。

**冷暖交替 = 叙事张力**。当一个场景从暖切到冷，观众能感受到情绪转换——即使他们没有意识到。

### 对比度控制

- **高对比**（纯白文字 + 纯黑背景 + 强 text-shadow）= 决定性瞬间。hook 场景、核心数据、高潮点。
- **中对比**（浅灰文字 + 深色背景）= 信息传递。正文、描述、功能说明。
- **低对比**（深灰文字 + 深色背景）= 氛围层。不该被第一眼注意到的装饰性信息。

### 光晕定位

大尺寸模糊光球（blur 140px）不是装饰——它是**氛围锚点**：
- **暖光在左上** + **冷光在右下** → 画面有纵深感和方向感
- **光晕位置跟随焦点** → 焦点在顶部时，光晕也偏上；焦点在底部时，光晕也偏下
- **双光晕一暖一冷** → 比单色光晕更有层次，避免画面"平"

### 留白密度

留白不是浪费空间，是**呼吸感**：
- **多留白（画面 40%+ 为空白）** = 高端、从容、呼吸感。适合：hook 场景（一句话冲击力）、climax（情感高点）
- **少留白（画面 20% 以下为空白）** = 紧迫、信息密集。适合：功能列表、数据展示、对比分析
- **同一视频内交替使用** → 用留白的多少制造节奏，不是所有场景都用同一个密度

### 动静节奏

- **快入快出（0.2-0.3s）** = 利落、专业、节奏紧凑。适合：列表项、标签、小元素入场
- **中速渐变（0.4-0.6s）** = 自然、舒适。适合：标题、主要文字
- **慢渐变（0.8-1.5s）** = 情绪化、沉浸。适合：phase 切换、氛围转变、climax 的视觉释放
- **静止** = 也是一种选择。不是每个元素都需要动画，静态本身是一种视觉力量

### 字号层级（按画布方向）

字号不只是"大小"，是**视觉权重**的物理表现。竖屏（1080×1920）和横屏（1920×1080）的画面比例完全不同，字号体系必须跟着变。

> 具体字号最低标准见 `shared/render-safety.md` §3。此表描述视觉权重层级和情感效果。

> **方向由 `design.md` 的 `orientation` 字段决定。** 未指定时按竖屏设计。仅当用户明确指定或分类配置要求时才使用横屏。

| 层级名称 | 情感效果 |
|---------|---------|
| 冲击层 | 震撼、不可忽视、占满视野 |
| 标题层 | 权威、聚焦、一读即懂 |
| 正文层 | 清晰可读、信息传递 |
| 标注层 | 可辨、不喧宾夺主 |

**字号铁律：**

1. **跨层级字号比 ≥ 2:1** — 最大和最小差距不到 2 倍，画面会"平"
2. 正文层不低于 `render-safety.md` §3 规定的最低值
3. 禁止小徽章标题（详见 `render-safety.md` §3.2）
4. 横屏字号整体小于竖屏（详见 `render-safety.md` §3.4）

## 第 3 层：导演笔记（爆款案例解码）

### 案例 1：GitHub Trending 爆款视频分析

| 决策 | 启示 |
|------|------|
| 金色 + 青色双色调 | 暖色 = 价值隐喻，冷色 = 技术隐喻，双色交替比单色有叙事性 |
| 每个项目独占一屏 8 秒 | 一次一个概念，聚焦单一故事 |
| 排名数字 120px + 金色 + text-shadow | 大字号 = 重要性排序的视觉锚点，快速划过也能捕捉 |
| 每场景一个暖光晕 + 一个冷光晕 | 比纯黑有温度，比单色有纵深。暖偏左上、冷偏右下 |
| 40px 网格背景 opacity 0.04 | 几乎不可见但存在——给纯黑添加"数字纹理" |
| 描述用灰色而非白色 | 信息层级：排名/星标 > 项目名 > 描述，灰色"可读但不抢" |

### 案例 2：色温叙事参考

| 技法 | 启示 |
|------|------|
| 大面积冷色中一个暖色焦点 | 制造视觉锚点（辛德勒名单原理） |
| 用色调编码内容类别 | 让观众凭直觉区分不同主题 |
| 同一颜色承载多层含义 | 颜色不是装饰，是叙事工具 |
| 光晕颜色暗示内容性质 | 理性/感性/技术/人文用不同色温表达 |
