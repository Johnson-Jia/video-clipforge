# Pattern Store 使用说明

## 什么是经验模式

经验模式（Pattern）是从高分成功案例中提炼的可复用知识。不同于规则（"不能做什么"），模式是"做什么效果好"。

## 生命周期

```
发现(Discover) → 验证(Validate) → 沉淀(Deposit) → 应用(Apply) → 淘汰(Retire)
```

| 阶段 | 条件 | 动作 |
|------|------|------|
| 发现 | 软评分 ≥ 0.85 的成功案例 | 提取关键决策点，识别重复模式 |
| 验证 | 同一模式在 ≥3 个案例中出现 | 统计置信度，检查与现有规则不冲突 |
| 沉淀 | 置信度 ≥ 0.8 且无冲突 | 以偏好/示例/放宽提案形式入库 |
| 应用 | 每次 Skill 执行时 | 按 skill_scope 过滤，注入 prompt |
| 淘汰 | 连续 30 天未命中或应用后评分下降 | 标记废弃，不再注入 |

## 三种沉淀方式

| 方式 | 触发条件 | 注入位置 |
|------|---------|---------|
| 偏好引导 | ≥3 个成功案例 | prompt "成功经验" 段 |
| Few-shot 示例 | ≥5 个案例且置信度 >0.8 | prompt few-shot 示例 |
| 约束放宽提案 | EXPERIENTIAL 约束频繁导致低分路径切换 | 人工审核后执行 |

## 消费方式

每次 Skill 执行前，约束引擎读取 `store.yaml`，按 `skill_scope` 过滤相关模式，将 `as_preference.text` 注入 prompt 的"成功经验"段。

## 治理

- 每周：有效性评估 + 冲突检测
- 每两周：模式淘汰（未命中或评分下降）
- 每月：跨 Skill 提升作用域评估
