4 旁白文案 (narration.txt) 对比

A: qwen-upgrade + Qwen3.7 最佳

Hook: "51万行源码泄露，53个工具，7个隐藏功能"

纯数据冲击开场，干净利落。
"但你知道吗？" 转折自然。
完整覆盖 hook→定位→门控→隐藏功能→竞品对比→洞察→CTA。
竞品对比有具体价格数据（"$200一个月"）。
节奏最紧凑，信息密度最高。

B: qwen-upgrade + GLM-5.1

Hook: "51万行源码泄露，Anthropic藏得最深的秘密，暴露了"

更戏剧化的开场。
类比有力："比瑞士军刀还精密""终端里的拓麻歌子"。
但缺失竞品对比具体数据。
整体信息覆盖较全但不如 A 紧凑。

C: main + GLM-5.1

Hook: "51万行源码泄露，Anthropic藏得最深的秘密，暴露了"

"手机上改完代码，到公司一看，已经在仓库里了"（具象场景）。

8 模型评估：GLM-5.1 vs Qwen3.7

GLM-5.1 视觉之王

擅长
  • HTML 视觉工程碾压级领先：角色系统、phase 切换、seeded 粒子
  • 元数据结构化最完整：visual_phases、contrarian_angle、character_expression
  • 设计文档深度最好：导演必答、精确配色规则
  • FX 动画类型最丰富（6+ 种 CSS 动画）
弱点
  • 旁白偶有遗漏（B 版缺失竞品对比数据）
  • 抖音文案版本少、传播力设计不足
  • 信息密度低于 Qwen
  • 偏描述性，hook 冲击力略弱

Qwen3.7 文案之王

擅长
  • 旁白节奏最紧凑，hook 最抓人
  • 信息密度最高：更少字传达更多数据
  • 抖音文案多版本 + 合规自查
  • 跨平台文案策略意识强
弱点
  • HTML 视觉偏简单，特效层弱
  • 无角色覆盖层、无语音气泡
  • 设计文档结构偏薄（A 版仅裸 YAML）
  • main 分支下抖音文案反而最弱

结论：main 分支在视觉产出上有明显优势，qwen-upgrade 在文案层面有优势。架构差异对视觉的影响（~2x 复杂度）大于对文案的影响（~10-20%），说明视觉质量对指令框架更敏感。

10 最终结论

综合排名

排名组合总分核心优势核心短板
1st main + GLM-5.1 32.0/35 视觉最震撼，时长最理想，元数据最完整 抖音文案不够丰富
2nd main + Qwen3.7 24.0/35 场景配色差异化最好，动画库最完整，时长理想 抖音文案最弱，HTML 复杂度中等
3rd qwen-upgrade + Qwen3.7 21.5/35 旁白最佳，抖音文案最全（合规检查） 视觉简单，75s 偏长，设计文档最差
4th qwen-upgrade + GLM-5.1 21.0/35 跨平台文案策略最全 HTML 最简单，特效为 0，竞品对比数据缺失

关键发现

1. 模型差异 > 架构差异。同一分支下换模型的视觉差异达 2-3 倍，同一模型换分支的文案差异仅 10-20%。视觉质量高度依赖模型能力。

2. GLM-5.1 是视觉引擎，Qwen3.7 是文案引擎。GLM 擅长 HTML 工程和动画系统，Qwen 擅长文案节奏和传播策略。两者能力互补。

3. main 分支的指令框架更成熟。导演必答、情绪曲线注解、幽默策略等框架有效提升了 GLM 的产出上限，但对 Qwen 的提升有限（Qwen 在 main 下的抖音文案反而更弱）。

4. 理想组合是拆不开的。GLM-5.1 做视觉 + Qwen3.7 做文案能产生最优结果，但当前管线是一个模型从头到尾执行。未来可探索模型分阶段调度。
